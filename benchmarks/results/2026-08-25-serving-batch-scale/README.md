# T2048/N64 serving batch scale

This matrix measures the retained no-flag exact Attention path and PyTorch ROCm
at batch 1, 2, 4, and 8. Each framework gets three fresh processes; process order
alternates. KV capacity is exactly T2048+N64.

```bash
ROCR_VISIBLE_DEVICES=0 HIP_VISIBLE_DEVICES=0 python3 \
  benchmarks/single_gpu/hf_inference_shape_matrix.py \
  --manifest /path/to/pinned-two-model-manifest.json \
  --micro-binary build/hip-release/apps/microllm_hf_infer \
  --pytorch-python /path/to/pytorch-rocm-python \
  --output-directory benchmarks/results/2026-08-25-serving-batch-scale \
  --models qwen2.5-0.5b,deepseek-r1-distill-qwen-1.5b \
  --contexts 2048 --batches 1,2,4,8 --decode-lengths 64 \
  --cases cached --micro-kv-cache-dtype bf16 \
  --micro-cache-capacity exact --warmup 2 --steps 5 --runs 3 \
  --allow-amdsmi-fallback
```

![Serving batch scale](batch-scale.svg)

Qwen microLLM scales 6.585x from B1 to B8 at 82.3% efficiency and remains
1.210x faster than PyTorch at B8. All four Qwen token sequences match. DeepSeek
scales 3.558x at B4 and 6.282x at B8, but efficiency falls from 89.0% to 78.5%; it
is 1.028x faster than PyTorch at B4 and 0.859x at B8.

DeepSeek cross-framework tokens match at B2/B4 but diverge from token index 2 at
B1/B8. microLLM uses mixed BF16 weights with FP32 activation boundaries while
PyTorch uses a full BF16 model, so this result records the failure and does not
assign it to one implementation without a complete-logit cross-batch audit.
No scheduler default is admitted.

AMDSMI reports zero devices in this container. The first attempt is preserved as
an environment failure outside the curated directory. The formal PyTorch run uses
the runner's explicit `amdsmi_zero_fallback_to_hip_runtime` path; all 24 PyTorch
records report that workaround and execute on the visible HIP device.

`raw.jsonl` and `summary.json` are authoritative. `analysis.json` is generated by
`render_serving_batch_scale.py`; `verification.json` pins the environment, clean
commit, route identities, and full gates.
