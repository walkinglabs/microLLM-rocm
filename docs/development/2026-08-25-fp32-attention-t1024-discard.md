# 2026-08-25 — 四个小测都赢，为什么最后还是不选

我们先让矩阵库为QK和PV各试64种算法。四道题都找到更快答案，最快约1.54倍。

但PV在模型里使用不同的内存排法。就像两张表都叫“名单”，一张按班级排，一张按姓氏排；给错
索引后程序虽然注册了它，却一次也没有真正使用。测试看到175次找不到、0次命中，立即停止。

QK的索引确实命中。Qwen整模快约5%，可完整词表分数误差放大到0.073；DeepSeek分数完全一样，
速度却只快0.2%。

![T1024 Attention solutions discard](../optimization-log/assets/fp32-attention-t1024-discard.svg)

所以“每个小测都有winner”不能推出“模型有一个共同winner”。默认策略拒绝，四个局部结果和两个
反例都留下。
