# 为什么十亿分之一的算子误差，最后会变成百分之一

## 单个算子看起来非常准

split-P×V把最后一长串加法分成16段。单个Attention输出与旧版本最多只差约十亿分之四。这个
数字很小，所以很容易说“精度没问题”。

## 模型不是只算一次

DeepSeek-Distill有28层，生成64个token时每一步又把新的结果送进下一步：

```text
很小的P×V差异
→ 后面的Linear、Norm、激活
→ 下一层Attention
→ 下一token再次进入28层
→ 完整词表分数差异逐步放大
```

最后303,872个logits中的最大差异变成0.064486，RMS为0.011488。64个argmax token仍相同，只能
说明当前prompt没有跨过top-1边界，不能说明概率分布相同。

## 为什么拒绝一个1.48倍的候选

它确实稳定快1.4834倍，peak和KV也没增加。但本项目的门是“速度和完整精度同时通过”，不是只看
输出文字碰巧一样。因此不会把它加入Auto，也不会继续用更多模型寻找一个好看的成功样例。

下一实验只能减少重复工作，不能改变每个head从position 0到T的加法顺序。跨GQA head复用value
load是一个可反驳候选；如果额外probability Tensor的成本仍太大，就接受这条局部路线已经饱和。
