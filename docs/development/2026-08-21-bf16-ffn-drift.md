# BF16 FFN internal drift and low-precision trace repair

The diagnostic BF16 FFN variant exposes device tensors for input cast, gate, up, activation and
down output while the default `bf16_ffn` keeps its unchanged null-diagnostic path.

The first run correctly failed because TraceSession silently emitted empty BF16 values. Trace value
capture now supports every floating dtype through the Tensor conversion contract and rejects
unsupported captured dtypes. Tests cover BF16 values, statistics and truncation.

Three official pairs then locate the first B1/B2 difference at gate GEMM: max 0.015625. The up GEMM
independently differs by 0.001953125; cast is exact. All 48 duplicate B2 stages remain exact.
