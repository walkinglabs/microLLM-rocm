# Arena-backed FFN region

## Implementation

- non-owning external Storage with explicit caller lifetime;
- caller-owned `swiglu_out_` for CPU and HIP;
- three aligned Arena intermediates plus stable output;
- Qwen/DeepSeek official FP32 FFN shapes;
- four-node heterogeneous Graph and setup break-even reporting.

## Result

Complete outputs are bit-exact. Qwen R32/R512 Graph improves 1.202×/2.970×, DeepSeek R512
improves 1.679×, while DeepSeek R32 is only 1.005×. The candidate remains shape-selective and
outside the production BF16 model path.

Full report: [Experiment 181](../optimization-log/experiments/181-arena-ffn.md).
