# 2026-08-25 — 为什么现在不该继续调小开关

把一次模型推理想成从学校回家的总路程。剩余两次 dtype 转换只是其中很短的两段路：
Qwen 占 Kernel 时间 2.694%，DeepSeek 占 1.841%。即使它们瞬间完成，总路程也最多
缩短到原来的 1/1.0277 和 1/1.0188。

![Current inference local saturation](../optimization-log/assets/inference-local-saturation.svg)

六条相邻的小优化已经由真实模型反例或 MI300X 后端能力测试关闭。因此本节点停止调整
当前默认推理路径的局部策略。下一步仍可继续优化，但任务必须是新的 kernel/图架构，或
转到仍有清晰热点和验收门的训练路径。

这里的“上限”只针对 Kernel 时间，并不代表端到端一定能得到同样收益；CPU、同步、加载
与采样时间只会让端到端收益更小。
