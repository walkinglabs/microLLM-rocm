# 2026-08-21 — BF16 KV Cache with an explicit safety boundary

## What changed

- `KVCache` now owns a public `Float32` or `BFloat16` storage policy; FP32 remains default.
- public generation can select the same policy through `GenerationConfig`;
- full prefill casts K/V once into capacity-strided BF16 Storage;
- step stores convert FP32 projected K/V to BF16 inside the HIP Kernel;
- fused and T>4096 cached Attention load FP32/BF16 K/V and always accumulate to FP32;
- CLI and matrix records expose Cache dtype, bytes and complete post-cache logits;
- the long fallback's batch probability offset was corrected and covered at B2 T4097.

## Evidence contract

The experiment changes only Cache storage width. Query, softmax, accumulation and output remain
FP32. Operator tests compare HIP against a BF16-rounded CPU reference. Official-model tests compare
every cached logit, top token, four greedy tokens, Cache bytes, throughput and peak memory across
Qwen/DeepSeek, context 32/512/2048 and batch 1/8.

## What failed

The 0.25 maximum-absolute and 0.05 RMSE gates were frozen before the long matrix. In the matched
Release build Qwen passes all six shapes and DeepSeek passes five; DeepSeek T512 B1 has RMSE 0.0586.
All 12 Release rows keep the same 16-token suffix. An ordinary-build diagnostic separately changed
a DeepSeek T2048 token, so that build-sensitive result is retained but not presented as the Release
outcome. BF16 Cache remains experimental and FP32 remains default.

Matched Release runs complete 72/72 process rows. Cache bytes halve on every shape; 11/12 shapes
improve, with DeepSeek T2048 B8 at 1.2478x and Qwen T32 B8 at 0.9957x. The retained Qwen T2048 B8
profile reduces cached Attention from 41.095 to 35.686 ms while adding 96 prefix cast launches.

A `bfloat162` candidate was also rejected. Pairing value columns reduced active threads in the
fused context phase and made T512 decode substantially slower. A second candidate that vectorized
only the key dot product still regressed. Both raw pilots are retained under Experiment 065.
