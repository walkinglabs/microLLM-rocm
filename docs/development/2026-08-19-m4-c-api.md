# 2026-08-19 — M4 versioned C API

## Contract

Expose a language-neutral ABI without leaking C++ classes, exceptions, STL types, or
HIP headers. Keep ownership explicit and make CPU-only and HIP-enabled builds use the
same header.

## API v1

- opaque `ml_tensor*` ownership with explicit destroy;
- float32 and int32 construction from host values;
- CPU/HIP device selection and transfer;
- rank, shape, element count, dtype, and device inspection;
- host copies for float32 and int32;
- add, multiply, matmul, and Softmax;
- engine/C-ABI version queries and HIP device count;
- status codes plus thread-local error messages;
- exceptions contained inside the shared-library boundary.

## Verification

A source file compiled as C links `libmicrollm.so`, constructs two matrices, checks
add and matmul hand values, exercises an invalid null input/error message, and, when a
HIP device is visible, transfers both matrices to GPU and checks HIP add after copying
the result back. It passes in both CPU-only and MI300X HIP builds.

2026-08-26 added ABI-compatible Event and owned-Stream functions: opaque ownership,
default/explicit record and wait, Event-only synchronization, elapsed time, four
Stream-routed operators and two caller-owned output paths. The shared library now exports
39 `ml_*` symbols with hidden C++ visibility after the non-owning native Stream wrapper.
The C test no longer uses standard
`assert`, because Release `NDEBUG` had removed the API calls themselves; an always-on
`CHECK` now executes the same CPU/HIP contract in Debug and Release.

## Boundary

API v1 owns/copies Tensor data and now owns optional Stream/Event handles. A future
versioned descriptor still needs non-owning external TensorView, native Stream ownership
rules and workspace for zero-copy PyTorch integration.
