# 2026-08-26 — 为什么O投影方案仍然不能默认开启

O投影可以理解为Attention交给后续网络前的最后一次“整理”。固定它的计算顺序后，完整输出的Max/RMS
误差改善24.7%/32.6%，说明前一份trace找对了位置。

但一次工程改动不能只看更漂亮的误差数字。B1 prefill从82.43ms变成87.32ms，只剩0.944×；B8的
Max误差也从0.000823升到0.001134。预先写好的合同要求每个batch至少0.95×，所以候选被拒绝。

本节点保留：

- O投影独立scope，供后续诊断；
- 16+16独立进程的原始JSONL、汇总和SVG；
- 一个自动化测试，锁定进程数、数值改善、B1失败、峰值和分配不变；
- 下一步真实upstream对选择性组合的实验合同。

本节点没有改默认模型行为，也没有把“更准确”写成“已经优化成功”。
